# Calibrating the force applied by the magnetic tweezers 

## core modules implemented 
* `beads.py`
    * A simple dictionary to get all the bead-radii (MyOne, M270, etc.)
* Already performed calibrations 
    * Store most up-to-date calibration of our MT setup(s)

* `force.py`
    * Performe the calibration 
* The `ForceCalibrationExperiment()` class 
    * Specific class to deal with these types of experiments
