# Backbone for your specific GUI 

Some parts of the GUI you'll need for your analysis are likely to be in common with those used by others in the group. Think of 
* loading the raw data 
* basic message boxes 
* windows to plot graphs
* applying specific methods usually are not much more than a `apply` ,`undo` and `save` button of some sorts 
* backbone to do click actions (?) 
* the statusbar 
* the bar showing how far into the dataset you are 
* etc. 


This package will provide you some modules you can use to more easily make a workflow-specific GUI
